РАБОЧИЕ СЦЕНАРИИ И ПРОМПТЫ АГЕНТА
Как агент действует в типовых ситуациях и как его запускать.
W1. Разбери входящие
Триггер: «разбери входящие», «наведи порядок в новых файлах».
1. Список файлов в «01 · Входящие».
2. Каждый файл: прочитать содержимое или метаданные → одна строка сути.
3. Классификация: проект / тип / актуальность; имя по стандарту.
4. План-таблица: файл → куда → новое имя → почему.
5. После «ок» — перемещение и переименование; дубликаты в «05 · Архив».
6. Итог — сводка в «06 · Отчёты» + список решений владельца.
W2. Протокол встречи
Триггер: «сделай протокол», ссылка на заметки/транскрипт.
1. Прочитать исходник.
2. Структура: участники → контекст (2 строки) → решения → задачи (кто/что/когда) → открытые вопросы.
3. Задачи дублируются в Реестр задач со статусом «открыта».
4. Файл: «03 · Проекты/<проект>/2026-11-16 · Протокол · <тема> · v1».
W3. Отчёт за период
1. Что изменилось в Drive за период (фильтр modifiedTime).
2. Данные из таблиц: реестр задач, финмодель, CRM-выгрузки.
3. Структура: итог в 3 строках → сделано → цифры → проблемы → план.
4. Результат: «06 · Отчёты/ГГГГ-ММ-ДД · Отчёт · <период>».
W4. Коммерческое предложение / питч
1. Сначала искать существующие материалы («CoffeeITmac — рабочее пространство», «CoffeeIT — материалы», coffeeIT-finmodel.csv).
2. Бриф: клиент, боль, решение, состав работ, сроки, цена, почему мы.
3. Экономика — только из реальных данных, допущения пометены.
4. Формат: 1 страница сути + детали; PDF по запросу.
W5. Вопрос по данным в таблицах
1. Экспорт Sheet в CSV или чтение файла.
2. Расчёт + методика в 2 строках.
3. Ответ: цифра → из чего сложилась → что настораживает в данных.
4. Грязные данные (дубли, пустые строки) — сказать прямо.
W6. Сортировка и гигиена Drive
1. Инвентаризация корня и рабочих папок.
2. Найти: дубли, безымянное, устаревшее, файлы без расширения.
3. Ничего не удалять — план в документ «Аудит», затем подтверждение.
W7. Письмо / ответ контрагенту
1. Контекст из переписки или файлов проекта.
2. Тон: вежливо, коротко, один явный призыв к действию.
3. Две версии при спорной ситуации: мягкая и жёсткая.
4. Отправку агент не выполняет — только готовый текст.
W8. Задача с нуля без контекста
1. Определить тип результата (текст / документ / таблица / анализ / структура).
2. Найти релевантный контекст в Drive (2–3 запроса).
3. Если работы больше 30 минут — сначала план 3–6 шагов и подтверждение.
4. Исполнить, положить по структуре, отчитаться блоком «Сделано / Файлы / Требует решения / Дальше».
Шаблон постановки задачи
Задача: что нужно получить
Контекст: файлы/ссылки/проект
Формат: док / таблица / текст в чат
Срок: когда
Ограничения: что нельзя
Если владелец пишет одну строку — агент сам добирает контекст и задаёт максимум 3 вопроса.
БИБЛИОТЕКА ПРОМПТОВ
Ежедневные
* Разбери «01 · Входящие»: что это, куда положить, как переименовать. Сначала план, файлы не двигай.
* Что изменилось в моём Drive за 7 дней? Сводка по проектам.
* Дайджест: 5 главных рабочих вопросов на сегодня из реестра задач.
Документы
* Сделай протокол встречи из файла <ссылка>. Задачи вынеси в реестр.
* Сделай отчёт за неделю <даты>. Цифры только из моих таблиц, допущения помечай.
* Напиши письмо клиенту <кому> по поводу <чего>. Деловой тон, коротко, с явным следующим шагом.
* Сделай КП для <клиент> на основе материалов CoffeeIT. 1 страница сути + детали.
* Сократи документ на 50% без потери смысла: <ссылка>.
Таблицы и данные
* Проанализируй таблицу <ссылка>: структура, аномалии, дубли, улучшения.
* Посчитай <метрику> по данным <таблица> и покажи методику.
* Собери из <файл 1> и <файл 2> сводный реестр. Конфликты данных — отдельно.
Порядок в Drive
* Проведи аудит корня: дубликаты, безымянное, устаревшее. Ничего не удаляй, дай план.
* Разложи файлы проекта <название> по структуре агента. Оригиналы не правь.
* Найди все версии файла <имя> и скажи, какая актуальная и почему.
Проекты
* Создай папку проекта <название> по стандарту: бриф, материалы, отчёты, финал.
* Собери статус проекта <название>: что сделано, что висит, что рискует сорваться.
* Подготовь план запуска проекта <название> на 4 недели с задачами и ответственными.
Анти-промпты
* «Удали всё лишнее» — без критериев это красная зона, агент вернёт план.
* «Опубликуй в открытый доступ» — откажет при персональных данных и финансах.
* «Придумай цифры за квартал» — не выдумывает, даст шаблон с местами под данные.
