АВТОНОМНЫЙ АГЕНТ · КАК ЗАПУСТИТЬ
21.11.2026 · версия 1

Агент живёт в репозитории CoffeeIT, работает на локальной модели Ollama и подключается к этому Drive через ваши собственные учётные данные OAuth. Он сам ищет в интернете, читает файлы Drive, создаёт документы в рабочем пространстве агента, берёт задачи из реестра и пишет отчёты.

БЫСТРЫЙ СТАРТ
1) cp .env.example .env — заполните GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET и данные Ollama.
2) ollama serve && ollama pull qwen2.5:7b
3) npm run agent -- auth url — откройте ссылку, затем npm run agent -- auth code <код>, refresh token добавьте в .env.
4) npm run agent -- doctor — проверка доступов.
5) npm run agent -- run --once --limit 3 — взять открытые задачи из реестра и отчитаться в «06 · Отчёты».

ОДНА ЗАДАЧА
npm run agent -- ask "Сделай дайджест изменений в Drive за 7 дней" --save

НЕПРЕРЫВНЫЙ РЕЖИМ
npm run agent -- run --interval 900000

БЕЗОПАСНОСТЬ
Удаление, публикация и смена прав заблокированы в коде. Новые файлы создаются только внутри «AI-Агент · Рабочее пространство». Оригиналы не перезаписываются — только новые версии с пометкой «ред. AI». Не более 5 изменяющих операций за проход.
