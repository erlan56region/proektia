# CoffeeIT

Стартовая страница и видеостудия, которая обрабатывает видео локально в браузере с помощью FFmpeg.wasm.

## Запуск

Нужен Node.js 18 или новее:

```sh
npm install
npm run dev
```

Откройте адрес, показанный в терминале, и выберите «Видеостудия». Для production-сборки: `npm run build`; папку `dist` можно разместить на статическом хостинге. Запускать файлы напрямую через `file://` нельзя: нужны HTTP(S) и поддержка WebAssembly и Web Workers.

Видеостудия соединяет клипы, обрезает их по времени и по желанию заменяет звук музыкой. Файлы и результат остаются в браузере. Суммарный размер файлов ограничен 200 МБ; фактические возможности зависят от памяти устройства. Движок загружается при первом экспорте (около 31 МБ), и обработка может занять время. Для видео без звука вставляется тишина. Видеомонтаж не использует искусственный интеллект.

FFmpeg.wasm и его ядро поставляются через npm. Ядро `@ffmpeg/core` распространяется по GPL-2.0-or-later; при развёртывании проекта необходимо соблюдать применимые условия лицензии FFmpeg и используемых кодеков.

## Автономный AI-агент

В репозитории есть локальный агент с мозгом на Ollama: он ищет в интернете, читает и создаёт файлы в Google Drive, берёт задачи из реестра и пишет отчёты. Инструкции загружены из Drive в `agent/prompts/`.

```sh
cp .env.example .env      # укажите данные для входа в Drive
ollama serve
ollama pull qwen2.5:7b
npm run agent -- doctor
npm run agent -- run --once
```

Подробная настройка, зоны полномочий и список команд — в [agent/README.md](agent/README.md).

## Сайт мебельной фабрики ТОК

В папке `mebel/` — отдельный многостраничный сайт фабрики дизайнерской мебели ТОК: главная, каталог, страница модели, серии, шоу-румы, новости, контакты и политика конфиденциальности. Это статический сайт на HTML, CSS и ES-модулях, без сборки зависимостей: каталог и цены лежат в `mebel/data.js` (данные серий с tok-mebel.ru), стили — в `mebel/styles.css`, изображения — в `mebel/images/`.

```sh
npm run dev:mebel      # только сайт ТОК: http://localhost:5173/
npm run dev            # весь репозиторий: сайт ТОК на /mebel/
npm run build          # dist/ вместе с dist/mebel/
```

После `npm run build` папку `dist/mebel` можно выложить на любой статический хостинг как самостоятельный сайт. Заявки в формах демонстрационные — данные не отправляются на сервер.

## Публикация на GitHub Pages

Сайт собирается GitHub Actions из `main` и публикуется по адресу <https://erlan56region.github.io/proektia/>. В настройках репозитория **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**, а окружение `github-pages` должно разрешать деплой из `main`. В сборку попадает только папка `dist`, а не исходные данные или настройки агента.
